Fonts used by the game UI (GameUI.java, OpeningScreen.java).

These are the two families fityeszthegame.com itself uses: Antonio for display
type and Public Sans for everything else, so the desktop build matches the site.

All are licensed under the SIL Open Font License 1.1, which permits bundling
them with this project. Full licence text:
https://openfontlicense.org/open-font-license-official-text/

  Antonio-Bold.ttf        Antonio         https://fonts.google.com/specimen/Antonio
  PublicSans-Regular.ttf  Public Sans     https://fonts.google.com/specimen/Public+Sans
  PublicSans-Italic.ttf   Public Sans     https://fonts.google.com/specimen/Public+Sans

Downloaded from Google Fonts. Each covers full Hungarian, including o-double-acute
and u-double-acute, so accented text renders without falling back to another face.
